ℹ️ How category rules work

  • Each row is a rule. When bank transactions are imported, the rules are checked from top to bottom and the first match wins.
  • Key words are separated with |. A rule matches if any key word appears (case-insensitive) in the debtor, creditor or description. Spaces count, so el differs from el.
  • From account limits the rule to one account (joint, anna, carlos). all applies it to every account. A rule with no account never matches.
  • Analytics: when Off, matching transactions are excluded from analytics.
  • Actions: 💾 saves the row, 📋 duplicates it just below, 🗑 deletes it. Edits are only stored after pressing 💾.
  • The + button adds a new rule at the top. Rules apply to future imports; existing transactions are not changed.
  • Transactions that match no rule are marked ⚠️ Review; Anna and Carlos transactions keep their personal category, while joint-account transactions use ⚠️ Review for both fields.
